Snowflake

A WebSocket relay with TurboTunnel, KCP, and smux. Looks like a website WebSocket. Carries TCP and UDP; forward and reverse on the same listener when target is set.

Use cases

  • Environments where WebSocket (or WSS) is allowed but raw TCP is not.
  • Optional domain fronting via sni / front-host.
  • Reach the WebSocket through an upstream proxy (proxy).

Example JSON (forward)

{
  "server": [
    { "type": "socks", "listen": "127.0.0.1:0", "tag": "exit" },
    {
      "type": "snowflake",
      "listen": "0.0.0.0:8080",
      "tag": "sf-public",
      "target": "exit",
      "tls-cert": "/etc/ssl/certs/server.crt",
      "tls-key": "/etc/ssl/private/server.key"
    }
  ],
  "client": [
    {
      "type": "snowflake",
      "listen": "127.0.0.1:1080",
      "address": "ws://203.0.113.10:8080/",
      "sni": "proxy.example.com",
      "front-host": "allowed.example.com",
      "proxy": "socks5://127.0.0.1:9050",
      "insecure": false,
      "tag": "sf-fwd"
    }
  ]
}

  "server": [

  ],
  "client": [
    {
      "type": "snowflake",
      "listen": "127.0.0.1:1080",
      "address": "wss://203.0.113.10:443/",
      "insecure": false
    }
  ]
}

Reverse client:

{
  "server": [
    { "type": "external", "listen": "127.0.0.1:22", "tag": "ssh" }
  ],
  "client": [
    {
      "type": "snowflake",
      "listen": "0.0.0.0:2222",
      "address": "ws://203.0.113.10:8080/",
      "reverse-tag": "ssh"
    }
  ]
}

Server fields

FieldRequired?DefaultMeaning / when required
typeRequired—snowflake.
listenOptional0.0.0.0:8080HTTP(S) bind for the WebSocket upgrade.
targetOptionalempty (reverse-only hub)Service tag for forward streams. Reverse binds are always allowed.
tagOptionalsnowflake-portLog label.
tls-cert / tls-keyOptional togetherempty = plain HTTP (ws)Both required for WSS. Paths to PEM cert and key.

Client fields

FieldRequired?DefaultMeaning / when required
typeRequired—snowflake.
addressRequired—ws://host:port/ or wss://host:port/.
listenOptional (forward); remote bind in reverse127.0.0.1:1080Forward: local TCP+UDP. Reverse: address published on the server.
reverse-tagOptionalempty = forwardService tag in this file’s server array.
sniOptionalemptyTLS Server Name (fronting / WSS).
front-hostOptionalemptyHTTP Host header for fronting.
proxyOptionalemptyUpstream proxy URL used to reach the WebSocket (e.g. socks5://127.0.0.1:9050).
insecureOptionalfalseSkip TLS verify for WSS.
tagOptionaltype-portLog label.

How it works

HTTP upgrades to WebSocket. A token and client ID select a packet queue. KCP runs in stream mode, then smux v2. Stream kinds match muxpipe (TCP, UDP, reverse bind/open).
