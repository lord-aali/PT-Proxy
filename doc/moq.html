MoQ carrier

Outer transport is Media over QUIC Transport draft 16 on a normal QUIC connection. The ALPN is moqt-16. After SETUP, each side announces the ptproxy namespace and subscribes to one track. Track up carries client-to-server frames and track down carries server-to-client frames. Each object payload is one encrypted carrier/core frame. Forward and reverse match the other carriers.

Example JSON (forward)

{
  "server": [
    { "type": "socks", "listen": "127.0.0.1:0", "tag": "exit" },
    {
      "type": "moq",
      "listen": "0.0.0.0:4433",
      "tag": "moq-public",
      "target": "exit",
      "enc-key": "change-me-please"
    }
  ],
  "client": [
    {
      "type": "moq",
      "listen": "127.0.0.1:1080",
      "address": "203.0.113.10:4433",
      "enc-key": "change-me-please",
      "tag": "moq-fwd"
    }
  ]
}

Server fields

  • listen — UDP bind for QUIC. Default 0.0.0.0:4433.
  • target — service tag for forward flows
  • enc-key — encrypts frames inside MoQ objects
  • pad-max / jitter-ms — optional shaping

Client fields

  • address — server host:port. moq:// is accepted and stripped.
  • listen — local TCP+UDP bind (forward) or remote publish address (reverse)
  • enc-key — must match the server
  • reverse-tag — optional

Notes

  • The listener uses a fresh self-signed certificate. The client does not check that certificate. enc-key is what authenticates the tunnel.
  • Allow UDP on the listen port. There is no TCP signaling port and no root requirement.
  • QUIC keepalive is 15 seconds. An idle session stays up for about two minutes without traffic.
