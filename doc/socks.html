socks

A SOCKS5 proxy this process listens for. Use it as a tunnel target (exit on the server) or as a reverse-tag (proxy on the client, published on the far side).

{ "type": "socks", "listen": "127.0.0.1:0", "tag": "exit" }

Capabilities

  • SOCKS5 CONNECT (TCP) to any destination the host can reach
  • UDP ASSOCIATE on the same port as TCP
  • Optional username/password (user / pass)
  • Port 0 — OS assigns a free port; the tag includes that port if you omit tag

Applications speak SOCKS5 to whatever address reaches this daemon (often the tunnel client’s listen in forward mode, or the reverse bind on the VPS).

How it works

TCP: standard SOCKS5 server. UDP: packets with a SOCKS5 UDP header are decoded, sent to the destination, and replies are wrapped and returned to that client. ASSOCIATE reports the listen IP so apps can send datagrams to this port.
