external

A name for a process that already listens somewhere. listen is the address to dial (SSH, a game, DNS, Tor ORPort, …). It is required.

{ "type": "external", "listen": "127.0.0.1:22", "tag": "ssh" }

Default tag is external- plus that port (external-22).

Capabilities

  • Forward: tunnel client local port ↔ this address
  • Reverse: this address (on the client machine) ↔ a port bound on the tunnel server
  • TCP streams and UDP datagrams to the same host:port

A TCP-only backend simply never sees UDP; a UDP-only backend never accepts TCP.

How it works

Nothing is bound. The registry stores the address. Tunnels Dial("tcp", addr) per stream and send UDP to that host:port. On obfs, a single raw TCP client (for example Tor to an ORPort) is spliced to this address without multiplexing.
