http

An HTTP proxy this process listens for. Typical use: browser or OS “HTTP proxy” pointed at a tunnel client listen, with this block as the tunnel server’s target.

Use cases

  • Forward exit: HTTPS and HTTP through CONNECT (and absolute-form HTTP) via a camouflage tunnel.
  • Reverse: publish this proxy on the tunnel server with reverse-tag.

Example JSON

{
  "server": [
    {
      "type": "http",
      "listen": "127.0.0.1:0",
      "tag": "webexit"
    }
  ]
}

Fields

FieldRequired?DefaultMeaning / when required
typeRequired—Must be http.
listenOptional127.0.0.1:0TCP bind only. Port 0 = OS assigns a free port.
tagOptionalhttp- + real portName for tunnel target / reverse-tag.

TCP only. Tunnels that target this tag do not carry UDP to it.

Capabilities

  • HTTP CONNECT — TCP through the proxy
  • Plain HTTP — one request/response to Host (port 80 if omitted)

Failed dials return HTTP 502.
