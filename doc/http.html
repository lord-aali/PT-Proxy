http

An HTTP proxy this process listens for. Typical use: browser or OS “HTTP proxy” pointed at a tunnel client listen, with this block as the tunnel server’s target.

{ "type": "http", "listen": "127.0.0.1:0", "tag": "webexit" }

Capabilities

  • HTTP CONNECT — HTTPS and other TCP through the proxy
  • Plain HTTP — one request/response to Host (port 80 if omitted)
  • Port 0 for an ephemeral listen

TCP only. Tunnels that target this tag do not carry UDP to it.

How it works

CONNECT: dial the requested host, respond 200 Connection Established, copy both ways. Other methods: dial the origin, write the request, copy the response. Failed dials return 502.
