PT Proxy documentation

PT Proxy is one binary and one JSON file. It runs camouflage tunnels and named services in the same process. The server array is listeners and backends this process owns. The client array is tunnels that connect out.

Building blocks

Services are what applications talk to, or what the tunnel dials:

  • socks — SOCKS5, TCP CONNECT and UDP ASSOCIATE on one port
  • http — HTTP CONNECT proxy (TCP)
  • external — any existing host:port (TCP and/or UDP)

Tunnels carry those flows across a hostile network. Each one can run forward (local port → tagged service on the far side) or reverse (far-side port → tagged service on this machine).

  • obfs2 / obfs3 / obfs4 — obfuscated TCP, Tor-compatible handshake
  • DPI — encrypted HTTP/HTTPS
  • Snowflake — WebSocket + KCP
  • FTP — FTP/FTPS façade with persistent data channels
