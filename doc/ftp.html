FTP tunnel

FTP/FTPS control plus persistent PASV data sockets. Control looks like FTP; data files look like web assets. Encrypted frame batches carry TCP and UDP. Forward and reverse are supported.

Use cases

  • Networks that allow FTP/FTPS outbound but block other tunnels.
  • Multiple parallel upload/download channels for throughput.
  • Optional decoy LIST/RETR cover traffic.

Example JSON (forward)

{
  "server": [
    { "type": "socks", "listen": "127.0.0.1:0", "tag": "exit" },
    {
      "type": "ftp",
      "listen": "0.0.0.0:21",
      "tag": "ftp-public",
      "target": "exit",
      "user": "tunnel",
      "pass": "secret",
      "enc-key": "change-me-please",
      "pasv-ip": "203.0.113.10",
      "upload-ports": "8080-8800",
      "download-ports": "8080-8800",
      "tls": false,
      "tls-cert": "/etc/ssl/certs/server.crt",
      "tls-key": "/etc/ssl/private/server.key"
    }
  ],
  "client": [
    {
      "type": "ftp",
      "listen": "127.0.0.1:1080",
      "address": "203.0.113.10:21",
      "user": "tunnel",
      "pass": "secret",
      "enc-key": "change-me-please",
      "upload-channels": 1,
      "download-channels": 1,
      "override-up-addr": "203.0.113.10:8080",
      "override-down-addr": "203.0.113.10:8081",
      "decoy": false,
      "tls": false,
      "verbose": false,
      "tag": "ftp-fwd"
    }
  ]
}

Reverse client:

{
  "server": [
    { "type": "external", "listen": "127.0.0.1:22", "tag": "ssh" }
  ],
  "client": [
    {
      "type": "ftp",
      "listen": "0.0.0.0:2222",
      "address": "203.0.113.10:21",
      "user": "tunnel",
      "pass": "secret",
      "enc-key": "change-me-please",
      "reverse-tag": "ssh"
    }
  ]
}

Server fields

FieldRequired?DefaultMeaning / when required
typeRequired—ftp.
listenOptional0.0.0.0:21FTP control listen address.
user / passOptionaltunnel / secretFTP login. Client must match.
enc-keyOptional (use a real secret)change-me-pleaseShared key for AES-GCM frame batches. Client must match.
pasv-ipStrongly recommended on public hostsemptyPublic IP advertised in PASV (227). Without it, clients may get a private IP.
upload-ports / download-portsOptional8080-8800Single port or N-M range for PASV data sockets.
targetOptionalemptyService tag for forward opens. Reverse binds still work when set.
tagOptionalftp-portLog label.
tlsOptionalfalseEnable FTPS. When true, tls-cert and tls-key are required.
tls-cert / tls-keyRequired if tls is trueemptyPEM paths for control/data TLS.
